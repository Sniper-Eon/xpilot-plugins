# 腾讯导航接入记录（2026-11-22）

本轮完成手机端基础腾讯来源适配，尚未完成高精车道驾驶替换。用户已授权实际切换；此前 C3 暂时离线，现已恢复连接。本轮已保存车机备份，未替换或重启车机运行软件，未做道路验收。

## 实际拿到的数据

- 前一轮腾讯自带模拟导航触发的样本：947 个引导区域中心线点、228 个车道组映射、22 个瓦片引用，包含左右边界车道 ID/比例等关联字段。序列化未截断、未出现读取失败。
- 这是引导区域的几何和关联，不等同于完整道路所有车道的边界坐标或车道连接表。几何原始坐标系、Z 单位和当前道路适用范围尚未完成验证。
- 本轮室外真实导航收到右转方向码 3、45 米距离、当前/下一道路名称及路线匹配。记录到新鲜的定位源时间、GPS 成功状态和非负路线匹配索引。
- 同一时段 HD 车道匹配索引仍为 -1，置信度为 0。负 workMode 的具体含义未标定，不据此猜测失败原因。没有确认本车处于某个绝对车道。
- SDK 道路匹配点有时报告 accuracy=0。本轮没有把 0 当成高精度，也不借用另一帧的精度给它赋值。

因此不能用现有样本判定三变五车道时哪一侧新增，也不能把 228 个车道组当成当前道路总车道数。

## 手机实现

候选身份仍是 `com.garan.tesnav.tenengkai.lane`，v67。手机已装早期 v67；最终增加 Android 用户隔离保护的候选包与早期版本号相同，安装结果需单独核对。原签名和数据保留。原有资产、动态库及 PNG/WebP 共 1706 项逐项哈希一致，包括侧方识别模型和玻璃 X 图标；未创建分身。

腾讯探针使用现有 SDK 实例，追加旧版 UI 导航、定位和 HD 定位观察者。没有替换腾讯自己的单导航监听器，没有创建另一套导航引擎。引擎模式来自既有导航器的真实/模拟/启动标志及定位提供器，既在周期检查时读取，也在导航/定位回调时重新读取。

SDK 在切路线时会清空 UI 观察者。重新订阅后，现用引擎路线可清除旧路线事实并建立新的路线代次；这一步不生成新的 guidance、位置或其观察时间。旧路线的迟到事件仍拒绝。

X-Pilot 增加“腾讯探针”来源，从手机回环接口读取。方向码使用该版本 SDK `Constants.IntersectionConstants`，不复用高德码表；方向码 3 另有真实界面和回调相互核对，其余已映射码仅完成静态 API 核对和离线测试。未知码保留未知。

保留独立 Android GNSS 的时效、精度、模拟定位和坐标系检查。新鲜、合格且已转换为 GCJ-02 的独立手机 GPS 优先；SDK 原始定位仅在自身合格时使用。手机 GPS 不能制造腾讯路线匹配，也不能更新腾讯引导时间。没有将特斯拉 CAN 描述为可用 GPS 来源。

以下条件撤销导航输入：模拟、模式未知、路线不一致、缺回调、源时间过期或未来、定位不合格、乱序及 SDK 进程重启。SDK 进程重启需重新选择来源。保存来源不等于恢复执行许可。

所有执行仍经现有 `navassist`、`ExtNavAssistEnabled` 和原生 SP/盲区/标线/路缘/驾驶员接管检查。本轮没有引入地图直接转向控制。腾讯的道路类型、车道箭头和绝对车道编号中尚未验证的字段不发送给 C3。

手机接收失败时，不沿用隐藏的高德路线。未获源门控许可时，对外发 idle，撤销位置、引导和车道字段，避免旧主机的仅打灯兼容路径继续引用旧指令。

## C3 候选修正（未部署）

备份确认当前主机为 `a0c4486247`，API 1 / ABI 2，导航插件 2.4.5-final。未切换系统、主机分支或固件。原有 DS 修复、中文界面和其他未提交改动保留。

发现旧接收端 1.5 秒有效性保持可跨越 routeActive=false、模拟/idle 或其他路线事件。旧行为先复现为 8 个失败案例；修正后 9 个案例通过。保持只适用于同一来源、路线和动作事件的短暂异常；显式撤销及新事件不能继承旧有效性。仅打灯关联也检查路线启用和匹配状态。

私有 C3 候选从本轮下载的运行备份生成，仅修改 `navstate.py` 与候选版本号 `2.4.6-tencent-source`，没有把本地其他脏文件整体覆盖进去。该准确备份候选的 9 个退出边界测试也通过。未上传、未安装、未激活，未发布插件商店。

250 / 800 / 640 / 400 米规划门槛及其原有文件未修改。腾讯尚未验证的道路类别不会冒充高德类别；不同道路类别的完整行为还需实测。

## C3 精度对照

用户报告此前 C3 的精度估计为 1.5–3 米，手机约 3–5 米。

本轮读取当晚最近原始日志：北京时间 22:20:04.5–22:20:30.5 的 27 条有效 gpsLocationExternal，来源 ublox，horizontalAccuracy 最小 2.276 米、中位数 2.409 米、最大 2.878 米。这是日志内精度估计，既不是实测最大位置误差，也不是当前实时定位。

当前车机 offroad，定位守护进程未运行；被动订阅 15 秒未收到新 GNSS。没有强制进入 onroad 或启动定位进程。当前导航输入无效，signalRequested、spLaneChangeReady、laneChangeAllowed 均为 false。

后续优先用同时段的原始 C3 GNSS、手机原始 GNSS 与腾讯匹配状态对照，核对来源独立性、同一坐标系、源时间、实际新鲜度和稳定性。原有转发代码会把大于 24.9 米的精度截成 24.9，已在运行备份确认；转发后的 accuracyValue 不能用于这种精度验收。本轮未改该既有脏文件或车辆执行路径。

有高精地图不等于已完成车道定位。可靠地图匹配、视觉/运动/惯性融合可以降低对单独 GNSS 的要求；本轮不新增“GPS 必须小于 1 米”条件。当前缺少有效车道匹配和完整车道连接几何，因此仍保留未知状态。
