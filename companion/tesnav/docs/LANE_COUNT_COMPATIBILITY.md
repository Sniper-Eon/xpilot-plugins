# 27 版：旧高德回调车道数一致性

旧 SDK 回调的原始 laneCount 与规范化车道明细可以不同，例如声明 6、实际返回 4 个条目，或原始数组带 255 填充。原代码保存规范化后的列表，却重新读取原始总数，可能发出“4 个条目、总数 6”。现在旧回调的 laneCount 与同一次规范化结果保持一致；空列表不保留原始总数。

不改变新版 SDK 回调的有效计数，不把多个方向箭头拆成多个车道，也不凭视觉可见数量裁剪高德的真实完整列表。高德的前方路口车道不一定等于当前位置断面的车道；本修复不证明地图数据准确，也不提供绝对本车车道定位。

验证：新增回调边界检查在旧代码失败、修复后通过；Kotlin 回放覆盖“声明 6、4 个条目、填充数组 → 总数 4、连续编号和推荐保持”。完整 Android 测试 347 项（346 通过、1 跳过），testDebugUnitTest / assembleTenengkai / compileReleaseKotlin 成功，地图显示检查 6 项通过。APK 为 27 / 1.14-xpilot-lane-count，沿用原包名与签名。手机无线 ADB 未发现，尚未安装或路测。
